Anonimizador
·

    Anonimize um documento sem tirá-lo desta máquina

    A detecção roda localmente. O arquivo final só é liberado depois de passar por uma verificação independente em dez frentes.

    Preparando…
    1. Enviando o arquivo
    2. Extraindo texto e detectando dados — alguns segundos por página
    3. Pronto
    • Sem rede O serviço que lê o documento roda sem rota para fora. Verificável com make ui-proof.
    • Redação de verdade O texto sai do arquivo, junto com metadados, anexos e sumário. Não é um retângulo por cima.
    • Você aprova Nada é gerado antes de você revisar e aprovar.

    Documento escaneado ainda não é suportado — sem texto no arquivo, não há o que remover.

    100%

    Não encontramos dados pessoais.

    Revise o documento ou adicione termos manualmente no campo acima.

    Formato de substituição

    Nos dois casos o valor é removido do arquivo, e não há mapa guardado para voltar atrás.

    Tarja preta. O valor some e o espaço fica coberto. Quem lê o documento não sabe que havia alguém ali, nem se é a mesma pessoa de outro trecho.

    Código no lugar. O valor some e um código ocupa o lugar. Quem lê sabe que havia uma pessoa — e que é a mesma pessoa dos outros trechos. É o formato para mandar o documento a uma análise automatizada.

    Nos dois casos o valor é removido do arquivo. O código é sorteado, não calculado a partir do dado: não existe chave, não há mapa guardado, e nem nós conseguimos voltar atrás.

    Perfis de detecção e regras salvas vão ficar aqui.

    Verificação

      O que você vai receber

      O mesmo documento, com os dados removidos do arquivo.
      Uma versão em texto, com um código no lugar de cada dado marcado — em todos, inclusive onde o PDF ficou em tarja. Gerada aqui, sem rede.
      Manda o texto com códigos a um modelo externo e mostra a resposta aqui.

      Para IA, recomendamos Código: ela entende que o mesmo código é a mesma pessoa.
